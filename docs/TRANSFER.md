# Transfer Manifest — everything added to build this project

A running list of every install and artifact, so this project can be rebuilt on
another machine. Kept up to date as the project grows. See the README's "Moving
this project" section for the short version.

Last updated: Phase 7 (2026-07-27). DB driver switched from psycopg (LGPL) to
pg8000 (BSD-3-Clause) to satisfy the "no copyleft" requirement; `pip-audit`
installed as a dev tool.

---

## 1. Machine-level installs (NOT inside the project folder)

These live outside `BMS-Cloud-Dashboard/` and must be reinstalled on the new
machine.

`daily_pack_report_archive` (`sql/daily_report.sql`), and `company`/`equipment`
